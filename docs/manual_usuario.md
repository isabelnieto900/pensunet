# Manual de usuario

Borrador. En la etapa 1 no hay interfaz gráfica: `pensunet.ui.ejecutar`
lanza `NotImplementedError`. El uso actual es desde Python y está
resumido en el `README.md` y en `examples/ejemplo_cargar_red.py`.

La simulación del tiempo de grado está disponible con
`simulador.simular(Escenario(...))`: devuelve la muestra de semestres
hasta el grado (variable X) bajo las tasas y la red cargadas.

Este manual se completará cuando haya una pantalla y un resultado de
simulación que explicar.
